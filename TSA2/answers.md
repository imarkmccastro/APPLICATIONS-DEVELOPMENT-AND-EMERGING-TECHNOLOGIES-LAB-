1. What is an Array?
An array is a variable that can store multiple values in a single variable.

2. What is a function in PHP?
A function is a block of code that performs a specific task and can be reused by calling its name.

3. Differentiate one-dimensional array from multi-dimensional array.
A one-dimensional array stores a single list of values. A multi-dimensional array stores arrays inside an array.

4. Difference between Global Variable and Local Variable.
A global variable is declared outside a function and can be accessed anywhere in the script. A local variable is declared inside a function and can only be used within that function.

5. Difference between function without parameter and function with parameter.
A function without parameter performs a fixed task without accepting any input. A function with parameter accepts input values that affect how it works.

6. Common Predefined Functions.
define() – declares a constant. Example: define("SITE_NAME", "My Resume").
include() – inserts a file and continues if it fails. Example: include("footer.php").
require() – inserts a file and stops if it fails. Example: require("header.php").
strlen() – returns the length of a string. Example: strlen("Hello") returns 5.
strtoupper() – converts a string to uppercase. Example: strtoupper("hello") returns "HELLO".
count() – counts the number of elements in an array. Example: count([1,2,3]) returns 3.

7. Is it useful to use include or require on a webpage? Why?
Yes, because it allows reusing code like headers and footers across multiple pages, making the website easier to maintain.

8. What is the importance of a function?
Functions make code reusable, organized, and easier to maintain by avoiding repetition.

9. What is the importance of a string function?
String functions make it easy to manipulate, format, and validate text data without writing complex code.
