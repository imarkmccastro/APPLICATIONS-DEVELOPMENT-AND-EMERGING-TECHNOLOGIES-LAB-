# PHP Arrays and Functions - Q&A
  
  ## 1. What is an Array?
  
  An array is a special variable that can store multiple values in one variable.
  
  ## 2. Differences between a Simple Variable and a Variable Array
  
  - **Simple variable** - stores only one value. Example: `$name = "Mark";`
  - **Variable array** - stores multiple values. Example: `$names = array("Mark", "Jovs", "Andrew");`
  
  ## 3. Instance Where You Can Use an Array
  
  Storing a list of student names to display in a class roster or table.
  
  ## 4. Different Array Sorting Functions
  
  - **sort()** - sorts values in ascending order (A-Z)
  - **rsort()** - sorts values in descending order (Z-A)
  - **asort()** - sorts values ascending, keeps keys
  - **arsort()** - sorts values descending, keeps keys
  - **ksort()** - sorts by key ascending
  - **krsort()** - sorts by key descending
  
  ## 5. What is a Function?
  
  A function is a block of code that performs a task and only runs when called.
  
  ## 6. Different Usage of Functions
  
  - Reuse code without rewriting it
  - Perform calculations (sum, average)
  - Validate user input
  - Organize code into smaller parts
  - Format or manipulate strings
